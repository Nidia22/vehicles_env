Análisis


Este proyecto fue para crear una aplicación web con Python y Streamlit para explorar y visualizar datos dentro del archivo vehicles_us.csv.

Se creo: 

Histograma: permite visualizar la distribución de los precios de los vehículos anunciados.

Gráfico de dispersión: permite explorar la relación entre el año del modelo y el precio de los vehículos.

Visualización interactiva: utiliza Plotly Express para generar gráficos interactivos que facilitan el análisis de los datos.

Librerias utilizadas

Python
Pandas
Streamlit
Plotly Express
